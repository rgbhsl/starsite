# Starsite
A personal website for the Stardance Challenge 2026, made with HTML and CSS.
![Screenshot of the first section from the website](image.png)

## Take a look at the rest: https://rgbhsl.github.io/starsite/

## Features
- 4 sections
- Multiple fonts, embedded image, rounded borders
- Simple CSS formatting

## Decisions
I am not too familiar with JavaScript so I had to rely on CSS to make it look more appealing. I used combinations of colors and fonts that would make it feel less monotonous while also being somewhat interesting visually. It's not the best website, but it's an attempt.
